# eyes

тут немного кода для запуска модели и работы с бд. как всё поднять на винде — ниже.

такие задачи вижу до следующего зума:

## 1. публикация

нашёл [работу от 8 апреля 2026](https://www.nature.com/articles/s41746-026-02598-2), делают очень близкое к нашему. тоже работают с видео бульбарной конъюнктивы, и первая часть обработки во многом нам подходит.

подготовь небольшой рассказ минут на пять: какие у них данные, как они их предобрабатывают, где используется модель и что получается после неё. какие части этого процесса можно взять для нашей задачи. можно буквально несколько слайдов со схемой и картинками. в первую очередь посмотри Figure 2 и раздел Methods → Video-to-Vessels.

## 2. параметры модели

сначала запусти ноутбук как есть. потом возьми одни и те же пять кадров разного качества и покрути масштаб изображения и порог маски. для начала масштаб `0.25` и `0.5`, порог `0.3`, `0.5`, `0.7`.

ещё интересно сравнить целый кадр и отдельные участки `128×128` и `256×256`. сейчас ноутбук обрабатывает кадр целиком, нарезку надо будет добавить.

меняй по одному параметру, чтобы было понятно, что повлияло. посмотри, где модель пропускает сосуды, где выделяет мусор и что происходит с толщиной. хочется картинки рядом и несколько предложений с наблюдениями.

## 3. что отдаёт модель

разберись, что получается на выходе сети до порога и как из этого делается маска. что означают большие и маленькие значения, можно ли считать их уверенностью модели? бывает ли, что значение высокое, а выделение неправильное? можем ли мы использовать этот скор, чтобы выбирать порог или находить сомнительные участки?

пока достаточно разобраться с готовой моделью. если что-то не получается или непонятно — тоже запиши, обсудим на зуме.

## запуск на винде

### 1. что установить

- [Python 3.12, Windows installer (64-bit)](https://www.python.org/downloads/release/python-31210/). при установке оставь Python Launcher и включи `Add python.exe to PATH`.
- [PostgreSQL 17](https://www.postgresql.org/download/windows/): PostgreSQL Server, Command Line Tools и pgAdmin. оставь порт `5432`, запомни пароль пользователя `postgres`. Stack Builder можно пропустить.

### 2. куда положить данные

скопируй папку `sample-500` с флешки в папку проекта:

```text
eyes/
  fr_unet.ipynb
  requirements.txt
  sample-500/
    database.dump
    files/
      ...avi
```

открой PowerShell в папке проекта. все команды ниже выполняй оттуда.

### 3. как открыть бд

после установки PostgreSQL уже работает как служба. если остановлен: `Win+R` → `services.msc` → `postgresql-x64-17` → «Запустить».

в каждой новой консоли для работы с бд:

```powershell
$env:Path = 'C:\Program Files\PostgreSQL\17\bin;' + $env:Path
```

создай базу и загрузи дамп — это делается один раз. команды запросят пароль `postgres`:

```powershell
createdb -h localhost -U postgres -T template0 -E UTF8 sample_500
pg_restore -h localhost -U postgres --no-owner --no-privileges --exit-on-error -d sample_500 .\sample-500\database.dump
```

посмотреть примеры запросов и открыть SQL-консоль:

```powershell
psql -h localhost -U postgres -d sample_500 -f .\inspect.sql
psql -h localhost -U postgres -d sample_500
```

выйти из SQL-консоли: `\q`. в pgAdmin база находится в `Servers → PostgreSQL 17 → Databases → sample_500`, таблицы — в схемах `dbo` и `cc_system`. `db.sh` — для macOS.

### 4. как запустить ноутбук

создай окружение и поставь зависимости — тоже один раз:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

запуск:

```powershell
.\.venv\Scripts\jupyter-lab.exe fr_unet.ipynb
```

в браузере нажми `Run → Run All Cells`. в первой ячейке меняются `VIDEO`, `N_FRAMES`, `SEED`, `SCALE`, `THRESHOLD`.

при первом запуске нужен интернет: ноутбук скачает код и веса модели, около 85 МБ. для ноутбука запуск бд не требуется — видео читаются прямо из папки.

данные передаются отдельно. перед коммитом ноутбука очисти вывод: `Kernel → Restart Kernel and Clear Outputs of All Cells`.
